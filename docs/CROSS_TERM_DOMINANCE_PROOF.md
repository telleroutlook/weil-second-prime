## 1. 命题对象

截断 Weil 二次型 Q_W^L,第二窗口 L∈((1/2)log3, log2)≈(0.549,0.693),
素数 2,3 均在单跳区,平移量 τ_p=log p/L。素数层是双平移对象,含交叉耦合
J(τ₂,τ₃) —— 第一窗口不存在的新结构。

Schur 判据:正定 ⟺ C = b_L·F − R_η ≻ 0,
F = T + M⁰ + M² − c_L·G,S⁰ 为完整四项 S_VV+S_VK+S_KV+S_KK。

判据对象统一为最小特征值 λ_min(非 min-pivot):由 Weyl 不等式
λ_min 是矩阵元的 Lipschitz 连续函数,避免 pivot 前主子式过零的不连续。

目标增量函数:
    Δλ^(N)(L) = λ_min(C_full^(N)(L)) − λ_min(C_off^(N)(L))
其中 C_off 是关掉交叉项(include_cross=False)的 Schur 矩阵。

关键恒等式(full 与 off 仅差 S2 中的交叉项,M2 相同):
    ΔC = C_full − C_off = −3·c₂·c₃·(F_ij + F_ji)   (精确 Arb 区间量)

## 3. Layer-2:N∈{6,8} 的 L-一致严格证明

### 3.1 验证特征值方法(严格性依据)

对每个宽度 10⁻³ 的子区间 I_k,闭式将其映射为区间对称矩阵
C(I_k)=C_c ± Δ(C_c 中点浮点矩阵,Δ 非负对称半径矩阵)。

λ_min 的严格下界(用于 C_full),三步:
1. 浮点求近似 (λ̃, ṽ),‖ṽ‖=1;切回 Arb 算严格残差 r = C_c ṽ − λ̃ ṽ。
2. Kato-Temple(需谱隙):λ_min(C_c) ≥ λ̃ − ‖r‖₂²/gap(或保守 λ̃ − ‖r‖₂)。
3. Weyl 对称扰动:任意 C(L)=C_c+E, E∈[−Δ,Δ],
   λ_min(C(L)) ≥ λ_min(C_c) − ‖Δ‖₂ ≥ λ_min(C_c) − ‖Δ‖₁。
   最终:λ_min^lower(C_full) = λ̃_full − ‖r_full‖₂ − ‖Δ_full‖₁。

λ_min 的严格上界(用于 C_off,更容易,Rayleigh-Ritz):
   任意单位测试向量 ṽ_off 的 Rayleigh 商即上界:
   λ_min^upper(C_off) = ṽ_off^T C_c,off ṽ_off + ‖Δ_off‖₁。

### 3.2 正确的非线性相减(关键)

λ_min 非线性,求差必须"下界 − 上界":
    inf Δλ = λ_min^lower(C_full) − λ_min^upper(C_off)
           = (λ̃_full − ‖r_full‖₂ − ‖Δ_full‖₁)
             − (ṽ_off^T C_c,off ṽ_off + ‖Δ_off‖₁)
两个 ‖Δ‖₁ 全转为减项,账本极保守。

### 3.3 谱隙分别验证(Kato-Temple 前提)

C_full 与 C_off 的谱隙分别独立验证,不可互相套用:
- C_full:λ₂−λ₁ > 0.8(已验证)。
- C_off(不定矩阵):切掉交叉项使 λ₁ 深陷(+0.077→−0.118)而 λ₂ 几乎不动,
  故谱隙反而更大(λ̃₁≈−0.118, λ̃₂≈1.0, gap>1.0)。Kato-Temple 对 off 分母
  更大、误差更小,验证合法。

### 3.4 依赖性问题未导致包络爆炸(为何选 10⁻³ 步长)

τ=log p/L,|dτ/dL|=log p/L²,L≈0.6 处最大 ≈ log3/0.36 ≈ 3.05。
δL=10⁻³ ⟹ 矩阵元变动幅度 ~3.05e-3;N=8 小矩阵下 ‖Δ‖₁ 总过估 ~O(1e-2)(约0.01–0.03)。
中点差 ~0.195 − 扰动 ~0.03 ≥ 0.160,包络不横跨0,严格下界存活。

### 3.5 全局一致下界(142 个子区间区间包覆,非网格采样)

遍历所有 I_k 提取下确界:
    N=6:  inf Δλ^(6) ≥ 0.160 > 0
    N=8:  inf Δλ^(8) ≥ 0.158 > 0

### 3.6 端点 Caveat

严格覆盖闭区间 [0.550, 0.692]。理论开窗口 (0.549,0.693) 两端约 10⁻³
条带豁免未证(需 10⁻⁵ 步长对抗端点敏感度才能升格)。L↓(1/2)log3
时素数3刚进场,有理闭式无极点、极限平稳,但端点敏感度未认证。

## 4. Layer-3:N→∞ 开放障碍(诚实卡点)

交叉项主导在无穷维极限是否存活(inf_N δ_N > 0?),是频域三者渐近阶的赛跑:
(a) 交叉项高频衰减:F_2i,2j 受 Legendre 边界跳跃支配,估计 O(1/k²)【有估计】
(b) 基态高频权重 w_2k 增长/迁移阶【缺解析估计】
(c) 竞争负项(单素数+残差 R_η)高频衰减阶【缺解析估计】

因 (b)(c) 缺失,不能武断判定。双向证据:
- 微弱萎缩:δ_6≈0.19526 → δ_8≈0.19521(降 ~5e-5),保留缓慢萎缩至0的风险;
- 反证:N=8 萎缩仍如此小,反证基态高频剧烈迁移假说,暗示 v_min 锚定低频
  (P_0,P_2),那里 F_ij ~ O(1) 无衰减 → δ_N 维持正下界是可能的。

需 N∈{10,12,16} 认证序列 + v_min 权重先验估计方可回答。当前诚实停步。
